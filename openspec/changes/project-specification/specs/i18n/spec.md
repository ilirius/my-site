## Purpose

Определяет требования к интернационализации: поддерживаемые языки, механизм переключения, автоопределение языка и структуру файлов переводов.

## ADDED Requirements

### Requirement: Поддержка русского и английского языков

Система SHALL поддерживать интерфейс на русском (ru) и английском (en) языках.

#### Scenario: Переключение языка

- **WHEN** пользователь меняет язык с русского на английский
- **THEN** весь интерфейс обновляется на английский язык

### Requirement: Автоматическое определение языка

Система SHALL автоматически определять язык пользователя по localStorage, затем sessionStorage, с фолбэком на русский.

#### Scenario: Первый заход с английской локалью в localStorage

- **WHEN** пользователь ранее выбрал английский язык и он сохранён в localStorage под ключом `i18nextLng`
- **THEN** интерфейс отображается на английском

#### Scenario: Первый заход без сохранённого выбора

- **WHEN** пользователь впервые заходит на сайт и в хранилищах нет ключа `i18nextLng`
- **THEN** система применяет русский язык как fallback

### Requirement: Файлы переводов

Переводы SHALL храниться в JSON-файлах по пути `public/locales/{lang}/translation.json`.

#### Scenario: Загрузка переводов

- **WHEN** приложение инициализирует i18next с плагином `i18next-http-backend`
- **THEN** переводы загружаются из соответствующего файла в `public/locales/`

### Requirement: Переключение языка в интерфейсе

Система SHALL предоставлять UI-элемент для ручного переключения языка на главной странице.

#### Scenario: Клик по иконке языка

- **WHEN** пользователь кликает по иконке RU/EN в верхнем правом углу
- **THEN** язык интерфейса переключается и сохраняется в localStorage

### Requirement: Интерполяция и Trans-компонент

Система SHALL поддерживать вставку HTML-тегов в переводы через `<Trans>` компонент `react-i18next`.

#### Scenario: Перевод с HTML-разметкой

- **WHEN** ключ перевода содержит `<0>Some text</0>`
- **THEN** контент внутри `<0>` рендерится как дочерний элемент, обёрнутый в соответствующий HTML-тег
