## Purpose

Синхронизация перечня секций SPA с каноническим набором макетов Google Stitch.

## MODIFIED Requirements

### Requirement: Одностраничное SPA с якорной навигацией

Сайт SHALL быть построен как одностраничное приложение (SPA). Все разделы — Главная, Обо мне, Опыт, Проекты, Технологический стек, Контакты — располагаются на одной странице (`/`) как последовательные секции и доступны по якорям `/#about`, `/#experience`, `/#projects`, `/#tech-stack`, `/#contact`. В будущем для проектов портфолио могут быть добавлены отдельные страницы (решение будет принято позже).

#### Scenario: Якорная навигация

- **WHEN** посетитель кликает по пункту меню «Обо мне»
- **THEN** страница плавно скроллится к секции About (якорь `#about`)
- **AND** URL в адресной строке обновляется на `/#about`

#### Scenario: Прямой переход по якорю

- **WHEN** посетитель открывает URL `https://pixel-and-code.dev/#projects`
- **THEN** страница загружается и скроллится к секции Projects
