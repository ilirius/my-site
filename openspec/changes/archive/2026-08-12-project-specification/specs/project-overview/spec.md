## Purpose

Описывает назначение проекта Pixel & Code — персонального сайта-портфолио Ивана Гаврилова, его целевую аудиторию и ключевые цели.

## ADDED Requirements

### Requirement: Персональное портфолио

Сайт SHALL представлять собой персональную страницу-портфолио Front-End разработчика Ивана Гаврилова.

#### Scenario: Посетитель заходит на сайт

- **WHEN** посетитель открывает главную страницу
- **THEN** он видит персональное портфолио с именем «Иван Гаврилов» и указанием профессии «Front-End Developer»

### Requirement: Одностраничное SPA с якорной навигацией

Сайт SHALL быть построен как одностраничное приложение (SPA). Все разделы — Главная, Обо мне, Навыки, Портфолио, Контакты — располагаются на одной странице (`/`) как последовательные секции и доступны по якорям `/#about`, `/#skills`, `/#portfolio`, `/#contact`. В будущем для проектов портфолио могут быть добавлены отдельные страницы (решение будет принято позже).

#### Scenario: Якорная навигация

- **WHEN** посетитель кликает по пункту меню «Обо мне»
- **THEN** страница плавно скроллится к секции About (якорь `#about`)
- **AND** URL в адресной строке обновляется на `/#about`

#### Scenario: Прямой переход по якорю

- **WHEN** посетитель открывает URL `https://pixel-and-code.dev/#skills`
- **THEN** страница загружается и скроллится к секции Skills

### Requirement: Адаптивный дизайн

Сайт SHALL корректно отображаться на устройствах с разными размерами экрана — от мобильных телефонов до десктопов.

#### Scenario: Просмотр на мобильном устройстве

- **WHEN** посетитель открывает сайт на устройстве с шириной экрана до 991px
- **THEN** макет адаптируется под вертикальную компоновку, меню трансформируется из ромбовидной формы в вертикальный список

### Requirement: Двуязычная поддержка

Сайт SHALL поддерживать русский и английский языки с возможностью переключения между ними и автоматическим определением языка браузера.

#### Scenario: Первое посещение с русской локалью браузера

- **WHEN** посетитель с русской локалью браузера впервые открывает сайт
- **THEN** интерфейс отображается на русском языке

### Requirement: Светлая и тёмная темы

Сайт SHALL поддерживать светлую и тёмную темы оформления с возможностью ручного переключения.

#### Scenario: Переключение на тёмную тему

- **WHEN** посетитель активирует переключатель темы
- **THEN** интерфейс переходит в тёмную тему, на `html`-элементе выставляется атрибут `data-theme="dark"`

### Requirement: Язык взаимодействия с AI-ассистентом

Взаимодействие с AI-помощниками (кодинг-агенты, Pi, код-ревью) SHALL вестись на русском языке. Английский допускается только для терминов, не имеющих устоявшегося русского аналога (например, SSG, PR, workspace).

#### Scenario: Разработчик общается с AI-ассистентом

- **WHEN** разработчик отправляет запрос AI-помощнику
- **THEN** AI-помощник отвечает на русском языке
- **AND** рассуждения (thinking) ведутся на русском
