## Why

Проект находится в состоянии миграции: старый код на CRA лежит в `src/`, а новый скелетон Turborepo + Next.js — в `apps/`. Между ними нет связи. Нужна задокументированная спецификация проекта, фиксирующая целевой техстек, архитектуру, методологию и план миграции. Это даст единый источник правды для всей дальнейшей разработки.

## What Changes

- **Фиксация целевого техстека**: Next.js 16 (SSG), React 19, TypeScript 5, SCSS/CSS Modules
- **Определение архитектуры приложения**: Feature-Sliced Design (FSD) в apps/web
- **Определение методологии UI**: Atomic Design в @repo/ui
- **Документирование структуры монорепо**: Turborepo + pnpm workspaces
- **Документирование i18n**: i18next (ru + en), автоопределение языка
- **Документирование тем**: Light/Dark через data-атрибут
- **Документирование плана миграции**: `src/` → `apps/web/`

## Capabilities

### New Capabilities

- `project-overview`: Назначение проекта, общее описание, целевая аудитория
- `tech-stack`: Полный перечень технологий, версий, инструментов сборки и проверки
- `architecture`: Архитектура монорепо, FSD-структура внутри apps/web, Atomic Design в @repo/ui
- `pages-and-routing`: Перечень страниц (Home, About, Skills, Portfolio, Contact, 404), роутинг на Next.js App Router
- `i18n`: Интернационализация — языки, библиотека, стратегия определения языка
- `theming`: Light/Dark темы, CSS-переменные, переключение по data-атрибуту
- `migration-plan`: План переноса кода из `src/` в `apps/web/`, статус текущей миграции
