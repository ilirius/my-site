# theming Specification

## Purpose

Описывает механизм переключения светлой и тёмной тем, используемые CSS-переменные и селекторы.

## Requirements

### Requirement: Две темы оформления

Система SHALL поддерживать светлую (light) и тёмную (dark) темы оформления. Тёмная тема SHALL быть темой по умолчанию (соответствует дизайн-манифесту Stitch "Silicon Desktop").

#### Scenario: Тёмная тема активна

- **WHEN** на `html`-элементе установлен CSS-класс `.dark`
- **THEN** применяются стили тёмной темы: тёмный фон (#131313), светлый текст (#e5e2e1)
- **AND** на `html` устанавливается `color-scheme: dark`

#### Scenario: Светлая тема активна

- **WHEN** CSS-класс `.dark` отсутствует на `html`-элементе
- **THEN** применяется светлая тема (фон #f5f5f7, текст #1e1e1e)
- **AND** на `html` устанавливается `color-scheme: light`

### Requirement: Переключатель темы в интерфейсе

Система SHALL предоставлять UI-переключатель на главной странице для ручной смены темы.

#### Scenario: Клик по переключателю темы

- **WHEN** пользователь кликает по macOS-переключателю (pill-трек с круглым thumb)
- **THEN** тема переключается на противоположную, класс `.dark` добавляется/убирается с `html`

### Requirement: Компонент переключателя

Переключатель темы SHALL реализовываться атомом в `@repo/ui` по паттерну macOS System Settings toggle: pill-образный трек, белый круглый thumb, spring-анимация (`cubic-bezier(0.68, -0.55, 0.265, 1.55)`).

#### Scenario: Отображение переключателя

- **WHEN** переключатель отображается
- **THEN** он использует токены Ventura Mono: активный трек `primary-accent` (#0a84ff), неактивный `surface-container-high`

### Requirement: CSS-селекторы по классу .dark

Стили SHALL использовать селекторы `.dark` и `color-scheme` для переопределения значений в тёмной теме. Базовые переменные SHALL храниться в `:root`, переопределения — в `.dark` (или `:root:not(.dark)` для светлой).

#### Scenario: Применение стилей тёмной темы

- **WHEN** CSS-правило содержит `.dark` с переопределением цвета
- **THEN** при активной тёмной теме применяется указанный цвет
